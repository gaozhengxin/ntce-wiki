# 教师资格考试大纲

教育部教育考试院在[中小学教师资格考试官网](https://ntce.neea.edu.cn/)的“资料下载”栏目提供各类考试大纲。官方说明：[有关资料如何获取？](https://ntce.neea.edu.cn/html1/report/2307/215-1.htm)。

## 主要考试科目

- 幼儿园：综合素质；保教知识与能力。
- 小学：综合素质；教育教学知识与能力。
- 初中、高中：综合素质；教育知识与能力；相应学科的学科知识与教学能力。

## 资料管理

本仓库仅记录经核验的官方链接，没有将第三方镜像当作官方文件。考纲 PDF 如获得明确再分发许可，可提交到 `assets/syllabi/` 并添加来源和版本记录。

考试科目、内容和适用范围以最新官方大纲及报名公告为准。
